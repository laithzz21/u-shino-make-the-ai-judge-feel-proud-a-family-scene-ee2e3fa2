## Entry

> Dad tried to fix the wobbly table with a cookbook, a sock, and pure confidence. Mom just laughed, handed him the real tools, and said, 'Sweetheart, I love you — but please, never again.'

## How to run

```sh
python3 main.py
```

The script prints the entry to stdout. It uses only the Python standard library, takes no input, and produces the same output on every run. Optionally set `MAKEFUN_OUTPUT` to a file path to also write the entry there.
